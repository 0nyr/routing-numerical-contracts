# Numerical checker contracts report

Research report comparing MAMUT-routing-lib 0.11.0 and 0.12.0 as distinct computational contracts, refined in s113 for arXiv and the v0.13 restoration process. The main argument covers ecosystem context, compatibility, fidelity, controlled Python performance and arithmetic design choices. Appendices retain full algorithms, provenance, detailed results and reproduction instructions. A table of contents, data availability statement and AI-use disclosure follow the established report style.

The public companion repository is [routing-numerical-contracts](https://github.com/0nyr/routing-numerical-contracts), cloned at `/home/onyr/code/phd/routing-numerical-contracts`. It contains the numerical code, compact input panels, historical candidate operands, provenance manifests and results, together with a synchronized report snapshot. The original private s108 investigation remains preserved independently.

The current bibliography records the agreed KAYROS and MAMUT author lists and cites the public KAYROS technical report v3. These citation updates preserve the experiment source revisions, frozen vendor files and numerical evidence. The report remains authored by Florian Rascoussier.

## Build

From `/home/onyr/code/phd/report`:

```bash
nix develop path:./nix-dev --command latexmk -pdf -interaction=nonstopmode -halt-on-error -cd numerical-checker-contracts/main.tex
```

Tables and standalone PDF figures are generated by the companion repository:

```bash
nix develop path:./nix-dev --command uv run python -m ncci.analyze --report-dir /home/onyr/code/phd/report/numerical-checker-contracts
nix develop path:./nix-dev --command uv run python -m ncci.report_study --report-dir /home/onyr/code/phd/report/numerical-checker-contracts
```

Run these commands from the public companion repository after restoring its evidence bundles. The bibliography uses biblatex and biber. The report recommends historical TD scoring and checker-based static ranking with canonical storage order. It is a research document for review, not an implemented v0.13 release or a recertification of the incumbent store.
